# Atelier Label

Impression d'étiquettes code-barres (Code 128, Data Matrix) sur imprimantes thermiques, pour macOS.

## Téléchargement

Les versions sont dans [Releases](../../releases) :

- **Mac Apple Silicon** (M1, M2, M3, M4…) : fichier `…-macOS-AppleSilicon.zip`
- **Mac Intel** : fichier `…-macOS-Intel.zip`

Configuration requise : macOS 13 Ventura ou plus récent.

## Installation

1. Décompresser le fichier et glisser **Atelier Label.app** dans le dossier Applications.
2. Au premier lancement, ouvrir **Réglages Système → Confidentialité et sécurité** et cliquer **Ouvrir quand même**.

Les versions suivantes s'installent ensuite directement depuis l'application.
